# Basic Rule-Based Chatbot 💬

A simple rule-based chatbot built in Python as part of the CodeAlpha Python Programming Internship.

## Description
The chatbot responds to a set of predefined user inputs like greetings and farewells using simple if-elif logic, simulating a basic conversational experience.

## Features
- Responds to common phrases like "hello", "how are you", and "bye"
- Randomized replies for a more natural feel
- Graceful fallback response for unrecognized input
- Runs in a continuous loop until the user exits

## Key Concepts Used
`if-elif`, functions, loops, input/output

## How to Run
```bash
python chatbot.py
```
